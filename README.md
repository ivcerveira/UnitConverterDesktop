# UnitConverterDesktop

Esqueleto de uma aplicação Desktop em Kotlin com Compose for Desktop.

## Abrir no IntelliJ IDEA

1. Abra a pasta `unit-converter-compose` no IntelliJ IDEA.
2. Aguarde a sincronização do Gradle.
3. Use JDK 17 ou superior.
4. Execute a função `main()` em `src/main/kotlin/com/example/unitconverter/Main.kt`.

A tela contém apenas o layout inicial do conversor. A lógica de conversão ainda não foi implementada.
